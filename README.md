# Java Core & OOP Practice Project

## Giới thiệu

Đây là dự án được xây dựng nhằm mục đích ôn tập và củng cố kiến thức Java Core và lập trình hướng đối tượng (Object-Oriented Programming - OOP) thông qua việc phát triển một ứng dụng quản lý sinh viên đơn giản.

Dự án tập trung vào việc áp dụng các kiến thức đã học vào một bài toán thực tế, từ đó giúp hiểu rõ hơn về cách tổ chức chương trình và tư duy lập trình hướng đối tượng.

---

## Mục tiêu

* Ôn tập cú pháp và các kiến thức nền tảng của Java Core.
* Áp dụng các nguyên lý của OOP vào quá trình thiết kế chương trình.
* Thực hành xây dựng chương trình theo hướng module, dễ mở rộng và bảo trì.
* Làm quen với việc tổ chức source code theo package và class.
* Rèn luyện kỹ năng thao tác với danh sách đối tượng và xử lý dữ liệu.

---

## Kiến thức được sử dụng

### Java Core

* Biến và kiểu dữ liệu
* Toán tử
* Cấu trúc điều kiện (`if`, `switch`)
* Vòng lặp (`for`, `while`, `do-while`)
* Mảng
* String và StringBuilder
* Exception Handling
* Collection Framework (`ArrayList`, `List`, ...)
* Generic
* File I/O (tùy chọn nâng cao)
* Regular Expression (nếu có)

### Object-Oriented Programming (OOP)

* Class và Object
* Constructor
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Interface
* Method Overloading / Method Overriding
* Static
* Package
* Access Modifier

## Chức năng của dự án

Ứng dụng mô phỏng hệ thống quản lý sinh viên với các chức năng cơ bản:

* Thêm sinh viên
* Hiển thị danh sách sinh viên
* Tìm kiếm sinh viên
* Cập nhật thông tin sinh viên
* Xóa sinh viên
* Sắp xếp danh sách sinh viên
* Lưu và đọc dữ liệu (tùy chọn nâng cao)
